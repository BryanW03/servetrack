# ServeTrack

A community service project and volunteer hour tracking app, built as the WDD 430 team project.

## Team Members

- Bryan De Leon ([@BryanW03](https://github.com/BryanW03)) — Team Leader (Week 03)

## About

ServeTrack helps a ward or community organize service projects and track how many hours each volunteer has logged. Core entities: `Volunteer`, `ServiceProject`, and `HourLog` (see `lib/types.ts`).

## Running Locally

```bash
npm install
npm run dev
```

Then open `http://localhost:3000`.

## Tech Stack

- Next.js (App Router) + TypeScript
- Tailwind CSS
- PostgreSQL (planned for Week 04+)
